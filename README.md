Доля покупок и игровой бюджет определяют деньги в канале; сделки, доход и ROI пересчитываются отдельно. Доход УК относится к группе. Вводные для ROI — условные, их можно заменить данными банка. Шрифты Inter и IBM Plex Mono распространяются по SIL OFL; лицензии находятся в `licenses/`.

## Статистика

CountAPI собирает открытия, уникальные браузеры, переходы по каждой ссылке, достижение разделов, PDF, шаринг и действия калькулятора. Статистика доступна на `stats.html`; эта страница себя не учитывает. Уникальность запоминается локально в браузере. Счётчики публичные; namespace и ID событий не являются секретными ключами.

В панели можно исключить собственный браузер. Для проверки используется отдельный контур: сайт с `?analytics=test`, статистика с `?test=1`. `?analytics=off` выключает отправку для текущего открытия. На localhost и в файле HTML отправка по умолчанию отключена. Данные начинают собираться с подключения счётчика, старые посещения не восстанавливаются.
