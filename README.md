# Инвестиции по ходу дела

Питч банкам от команды doomers.

- [Сайт](https://bavadim.github.io/bank-in-any-agent/)
- [PDF, 15 страниц](https://bavadim.github.io/bank-in-any-agent/doomers-pitch.pdf)
- [Автономный HTML](https://bavadim.github.io/bank-in-any-agent/bank-in-any-agent.html)

PDF содержит весь питч, источники, методологию и примеры. Калькулятор представлен статичной инфографикой с параметрами по умолчанию.

Для просмотра без сети используйте `bank-in-any-agent.html`: шрифты, изображения и PDF встроены. `index.html` — версия сайта с ресурсами из `assets/`.

Факты, прогнозы и гипотезы отмечены отдельно. Параметры калькулятора — сценарные допущения зрелого канала. Воронка начинается с доли аудитории Ozon. Доля покупок и игровой бюджет определяют деньги в канале; сделки, доход и ROI пересчитываются отдельно. Доход УК относится к группе. Вводные для ROI — условные, их можно заменить данными банка. Шрифты Inter и IBM Plex Mono распространяются по SIL OFL; лицензии находятся в `licenses/`.
