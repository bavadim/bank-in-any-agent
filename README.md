# doomers · Первый взнос по ходу дела

Инвесторский питч. Первый целевой пилот: стилист и Ozon от doomers → инвесткопилка Т‑Инвестиций. Партнёрство и выплаты не подтверждены.

- [Сайт](https://bavadim.github.io/bank-in-any-agent/)
- [Статистика посещений и кликов](https://bavadim.github.io/bank-in-any-agent/stats.html)
- [PDF, 11 страниц](https://bavadim.github.io/bank-in-any-agent/doomers-pitch.pdf)
- [Автономный HTML](https://bavadim.github.io/bank-in-any-agent/bank-in-any-agent.html)

PDF содержит весь питч, источники, методологию и примеры. Калькулятор представлен статичной инфографикой с параметрами по умолчанию.

Для просмотра без сети используйте `bank-in-any-agent.html`: шрифты, изображения и PDF встроены. `index.html` — версия сайта с ресурсами из `assets/` и источник для обеих сборок.

Чтобы пересобрать PDF и автономный HTML, запустите `python build-editions.py --chromium /путь/к/chromium` в среде с пакетом `websockets` (версия 12 или новее). Сборщик запускает headless Chromium без песочницы; используйте его только для доверенного локального исходника.

Калькулятор показывает стоимость дополнительной активации для поставщика и маржинальный вклад на активированного пользователя для doomers. Стартовые вводные иллюстративные; в PDF они статичны. Историческая банковская редакция сохранена в коммите `a350adf`. Шрифты Inter и IBM Plex Mono распространяются по SIL OFL, лицензии находятся в `licenses/`.

## Статистика

CountAPI собирает открытия, уникальные браузеры, переходы по каждой ссылке, достижение разделов, PDF, шаринг и действия калькулятора. Статистика доступна на `stats.html`; эта страница себя не учитывает. Уникальность запоминается локально в браузере. Счётчики публичные; namespace и ID событий не являются секретными ключами.

В панели можно исключить собственный браузер. Для проверки используется отдельный контур: сайт с `?analytics=test`, статистика с `?test=1`. `?analytics=off` выключает отправку для текущего открытия. На localhost и в файле HTML отправка по умолчанию отключена. Данные начинают собираться с подключения счётчика, старые посещения не восстанавливаются.
