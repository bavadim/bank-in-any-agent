# Банк в чужом окне

Презентация идеи для банковского хакатона. Четыре основания: смена точки входа, композиция сервисов без прямого партнёрства, масштаб аудитории и бытовая цель с игровой механикой.

Факты, прогнозы и гипотезы отмечены отдельно. Ссылки на исследования размещены на странице. Финансовые показатели калькулятора — сценарные допущения.

Откройте `index.html` в браузере. Страница автономна: изображения, шрифты и интерактив встроены, подключений к брокерским счетам нет.

Шрифты Inter и IBM Plex Mono распространяются по SIL Open Font License; тексты лицензий находятся в `licenses/`.
